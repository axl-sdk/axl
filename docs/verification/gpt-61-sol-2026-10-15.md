# GPT-6.1 Sol live verification

**Date:** 2026-10-15. **Verdict:** live-verified with the limits below.
The owner authorized bounded paid checks using the existing worktree credentials.
Only `gpt-6.1-sol` was selected in the completed runs. Requests used small fixed
prompts and output caps of 64–256 tokens; the tool returned a fixed local value.

## Results

| Scenario | Endpoint | Result |
| --- | --- | --- |
| Text and strict JSON schema | Responses | Passed, including usage and positive estimated cost |
| Function tool call and result continuation | Responses | Passed, including metered continuation |
| Terminal streaming usage and estimated cost | Responses and Chat | Both passed |
| Text | Chat | Passed, including usage and positive estimated cost |
| Portable temperature with omitted effort | Responses and Chat | Both passed; captured bodies omit temperature, top_p, and explicit effort |
| Portable `none` | Responses and Chat | Both passed; captured wire effort is `low` |
| Portable `max` | Responses | Passed with native `max` |
| Portable `max` | Chat | Passed after correcting the adapter to send `xhigh` |

The first seven tests passed in 47.98 seconds. Four additional effort tests
initially produced three passes and one HTTP 400. Chat rejected native `max`:
"Supported values are: 'low', 'medium', 'high', and 'xhigh'."
Responses accepted `max`. The exact-model descriptor now reflects that endpoint
difference: portable Chat `max` clamps to `xhigh` with a diagnostic, while raw
Chat `reasoning_effort: 'max'` is rejected locally. The corrected Chat test passed
in 2.76 seconds. All eleven selected scenarios therefore have passing evidence;
this was not a single eleven-test run.

## Reproduction

From the repository root:

```sh
pnpm --filter @axlsdk/axl exec vitest run --config vitest.frontier-integration.config.ts src/__tests__/integration-latest-models.test.ts -t 'gpt-6\.1-sol|GPT-6\.1 Sol' --maxWorkers=1
```

The seven original tests ran before the four effort cases were added. The
additional cases used `-t 'GPT-6\.1 Sol .*accepts portable effort'`; the final
rerun used `-t 'GPT-6\.1 Sol openai accepts portable effort max'`.
An initial package-script invocation with an ambiguous `--` forwarding boundary
was interrupted before any completed result was captured; it is not evidence
for certification or a reliable request-count/spend total.

## Limits

- Costs asserted here are Axl estimates from returned usage, not invoice audits.
  No aggregate spend was captured. Long-context and cache-write billing remain
  verified by local arithmetic tests and published rates, not live invoices.
- This does not certify every effort level, regional processing, Fast/Ultrafast,
  media, hosted tools, or unknown snapshots. Unsupported billing remains unpriced.
- Chat tool rejection, raw invalid-option rejection, and clamp diagnostics have
  local tests; successful live requests establish acceptance of the resulting
  supported wire forms, not those local rejection paths.
